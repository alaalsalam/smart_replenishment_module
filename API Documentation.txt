# Smart Replenishment Module - API Documentation

## Authentication

All endpoints require API key-based authentication.

**Header Example:**

```
Authorization: token {{api_token}}:{{api_secret}}
```

## Base URL

```
{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api
```

## 1. Get Recommendations

**Description:** Retrieve replenishment recommendations with filtering and pagination.

**Method:** GET

**Endpoint:** `{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.get_recommendations`

**Authorization:** API key

- **Key:** Authorization
- **Value:** token {{api_token}}:{{api_secret}}

**Query Parameters (optional):**

    Content-Type: application/json
    
    {
        "filters": {
            "status": "Pending|Approved|Ordered|Rejected",
            "priority": "High|Medium|Low",
            "warehouse": "Warehouse Name",
            "item_code": "Item Code",
            "item_group": "Item Group Name"
        },
        "page": 1,
        "page_size": 20,
        "sort_by": "priority"
    }

**Parameters Description:**

- **filters** (JSON object, optional): Filter criteria
  - status: Workflow state (Pending, Approved, Ordered, Rejected)
  - priority: Priority level (High, Medium, Low)
  - warehouse: Warehouse name
  - item_code: Item code
  - item_group: Item group name
- **page** (Integer, optional): Page number (1-based, default: 1)
- **page_size** (Integer, optional): Records per page (default: 20)
- **sort_by** (String, optional): Sort field options: "priority", "created", "current_stock_qty" (default: "priority")

**Note:** Status values represent workflow states: Pending (draft), Approved/Rejected/Ordered (submitted).

**Example Request:**

```bash
curl -X GET \
  '{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.get_recommendations?filters={"status":"Pending","priority":"High"}&page=1&page_size=20' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: token {{api_token}}:{{api_secret}}'
```

**Expected Response:**

- **Status:** 200 OK
- **Response Body:**

```json
{
  "message": {
    "data": [
      {
        "name": "REP-REC-2025-00001",
        "item_code": "ITEM-001",
        "item_name": "Paracetamol 500mg",
        "warehouse": "Main Warehouse - Company",
        "status": "Pending",
        "priority": "High",
        "current_stock_qty": 200.0,
        "reorder_point": 450.0,
        "recommended_order_qty": 500.0,
        "average_daily_consumption": 50.0,
        "lead_time_days": 7,
        "safety_stock_days": 2,
        "preferred_supplier": "Supplier-001",
        "estimated_cost": 2500.0,
        "purchase_order": null,
        "creation": "2025-01-15 10:30:00",
        "modified": "2025-01-15 10:30:00"
      }
    ],
    "total_count": 1,
    "page": 1,
    "page_size": 20,
    "total_pages": 1
  }
}
```

**Error Responses:**

- **Status:** 400 Bad Request - Invalid parameters
- **Status:** 401 Unauthorized - Invalid or missing authentication
- **Status:** 500 Server Error - Internal server error

## 2. Trigger Recommendation Generation

**Description:** Manually trigger recommendation generation. This endpoint scans inventory and creates recommendations for items below reorder points.

**Method:** GET

**Endpoint:** `{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.trigger_recommendation_generation`

**Authorization:** API key

- **Key:** Authorization
- **Value:** token {{api_token}}:{{api_secret}}

**Query Parameters (optional):**

    Content-Type: application/json
    
    {
        "warehouse": "Main Warehouse - Company"
    }

**Parameters Description:**

- **warehouse** (String, optional): Filter by specific warehouse. If not provided, scans all warehouses.

**Example Request:**

```bash
curl -X GET \
  '{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.trigger_recommendation_generation?warehouse=Main Warehouse - Company' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: token {{api_token}}:{{api_secret}}'
```

**Expected Response:**

- **Status:** 200 OK
- **Response Body:**

```json
{
  "message": {
    "status": "success",
    "created_count": 5,
    "skipped_count": 10,
    "total_processed": 15,
    "errors": []
  }
}
```

**Note:** The system automatically prevents duplicate recommendations. If a pending or approved recommendation already exists for an item-warehouse combination, it will be skipped.

**Error Responses:**

- **Status:** 500 Server Error - Internal server error

## 3. Approve Recommendation

**Description:** Approve a pending replenishment recommendation. Only recommendations with status "Pending" can be approved.

**Note:** Status changes are managed by the workflow system. In the UI, use workflow actions (Approve/Reject buttons) instead of manually changing the status field. This API endpoint is available for external integrations that need to programmatically approve recommendations.

**Method:** POST

**Endpoint:** `{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.approve_recommendation`

**Authorization:** API key

- **Key:** Authorization
- **Value:** token {{api_token}}:{{api_secret}}

**Request Body:**

    Content-Type: application/json

    {
        "recommendation_name": "REP-REC-2025-00001"
    }

**Parameters Description:**

- **recommendation_name** (String, required): Name of the recommendation document to approve

**Example Request:**

```bash
curl -X POST \
  '{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.approve_recommendation' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: token {{api_token}}:{{api_secret}}' \
  -d '{
    "recommendation_name": "REP-REC-2025-00001"
  }'
```

**Expected Response:**

- **Status:** 200 OK
- **Response Body:**

```json
{
  "message": {
    "status": "success",
    "recommendation": "REP-REC-2025-00001",
    "new_status": "Approved"
  }
}
```

**Error Responses:**

- **Status:** 400 Bad Request - Recommendation not in Pending status
- **Status:** 500 Server Error - Internal server error

## 4. Create Purchase Order

**Description:** Create a Purchase Order from an approved replenishment recommendation. The recommendation must be in "Approved" status.

**Method:** POST

**Endpoint:** `{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.create_purchase_order`

**Authorization:** API key

- **Key:** Authorization
- **Value:** token {{api_token}}:{{api_secret}}

**Request Body:**

    Content-Type: application/json

    {
        "recommendation_name": "REP-REC-2025-00001"
    }

**Parameters Description:**

- **recommendation_name** (String, required): Name of the approved recommendation document

**Example Request:**

```bash
curl -X POST \
  '{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.create_purchase_order' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: token {{api_token}}:{{api_secret}}' \
  -d '{
    "recommendation_name": "REP-REC-2025-00001"
  }'
```

**Expected Response:**

- **Status:** 200 OK
- **Response Body:**

```json
{
  "message": {
    "status": "success",
    "purchase_order": "PUR-ORD-2025-00001",
    "supplier": "Supplier-001",
    "company": "Company",
    "total_amount": 2500.0
  }
}
```

**Note:**

- The system automatically determines the supplier using this priority:
  1. Preferred supplier from recommendation
  2. Preferred supplier from Item Reorder settings
  3. Default supplier from Item Supplier table
- The recommendation status is automatically updated to "Ordered" and linked to the created Purchase Order.
- Purchase Order items include `last_purchase_rate` for tracking.
- If supplier is not found, the request will fail with a 400 error.

**Error Responses:**

- **Status:** 400 Bad Request - Recommendation not approved, supplier not found, company not found, etc.
- **Status:** 500 Server Error - Internal server error

## Error Response Format

All endpoints return errors in the following format:

```json
{
  "message": {
    "status": "error",
    "message": "Error description here"
  }
}
```

**Common Error Messages:**

- `"Only approved recommendations can be converted to Purchase Orders"`
- `"No supplier found for Item [item_code]. Please set a preferred supplier or default supplier."`
- `"Only pending recommendations can be approved. Current status: [status]"`
- `"Company not found for Warehouse [warehouse]"`
- `"Purchase Order [po_name] already exists for this recommendation"`
- `"Status cannot be changed manually. Please use workflow actions (Approve/Reject) to change status."`

## Example Use Cases

### 1. Mobile App Integration

A mobile app for pharmacy managers needs to display pending recommendations:

```javascript
// Fetch high-priority pending recommendations
const response = await fetch(
  '{{base_url}}/api/method/smart_replenishment_module.api.recommendation_api.get_recommendations?' +
  'filters={"status":"Pending","priority":"High"}&page=1&page_size=50',
  {
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'token {{api_token}}:{{api_secret}}'
    }
  }
);
const data = await response.json();
const recommendations = data.message.data;
```

### 2. Automated Approval Workflow

Automatically approve recommendations for low-priority items:

```javascript
// Get low-priority pending recommendations
const recommendations = await getRecommendations({
  status: 'Pending',
  priority: 'Low'
});

// Approve each one
for (const rec of recommendations) {
  await approveRecommendation(rec.name);
}
```

### 3. Bulk Purchase Order Creation

Create Purchase Orders for all approved recommendations:

```javascript
// Get approved recommendations
const recommendations = await getRecommendations({
  status: 'Approved'
});

// Create PO for each
for (const rec of recommendations) {
  await createPurchaseOrder(rec.name);
}
```
